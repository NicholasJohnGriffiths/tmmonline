# Migration Execution Sheet

Use this sheet to track page-by-page migration work for TMMOnline.

File:
- migration-output/migration-execution-sheet.csv

## Columns
- Phase
- Priority
- Url
- Title
- SuggestedDocTypeAlias
- SuggestedTemplate
- InternalLinks
- MediaLinks
- Owner
- Status
- QA
- Redirect
- Notes

## Suggested Status Values
- Not Started
- In Progress
- Ready for QA
- Blocked
- Done

## Suggested Workflow
1. Assign an owner.
2. Migrate content and media.
3. Verify redirects.
4. Complete QA.
5. Mark Done.
