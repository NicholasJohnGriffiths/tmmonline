# uSync Scaffold for TMMOnline

This folder is a practical scaffold for recreating the TMMOnline content model in a uSync-style structure.

It is intentionally simple and mirrors the three core document types and two compositions defined in the repo docs.

## Contents

- ContentTypes/PageSeo.json
- ContentTypes/PageContent.json
- ContentTypes/HomePage.json
- ContentTypes/SectionPage.json
- ContentTypes/ArticlePage.json
- Templates/HomePage.json
- Templates/SectionPage.json
- Templates/ArticlePage.json

## Important

- Treat this as a migration scaffold, not a guaranteed drop-in export from uSync.
- Confirm the exact uSync version and export schema before using these files for an automated import.
- The stable aliases in the repo are:
  - pageSeo
  - pageContent
  - homePage
  - sectionPage
  - articlePage
