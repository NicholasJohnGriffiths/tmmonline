# Import Order

Use this order when recreating or importing the TMMOnline content model.

## Order

1. Page SEO composition
2. Page Content composition
3. Home Page doctype
4. Section Page doctype
5. Article Page doctype
6. HomePage template mapping
7. SectionPage template mapping
8. ArticlePage template mapping

## Notes

- Keep aliases stable while importing.
- Apply compositions before assigning templates.
- Create the root content node only after the doctypes exist.
- Do not start page content migration until this order is complete.
